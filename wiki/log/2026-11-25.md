## Port-path comparison

- Measured the import surface from `names/ps5_eboot_imports.tsv`: **56 libraries,
  730 stubs, `libSceAgc` 78**. That number is the argument: recompiling and
  emulating both hinge on translating AGC command streams and RDNA2 shaders,
  not on reimplementing the renderer. See [[port-paths]].
- PS4 specifically: [[ps4-route]]. EmuFive already runs PS5 titles on PS4
  (KytyPS5 + Mesa/RADV, 287 AVX2/FMA/BMI2 forms rewritten), so the CPU gap is
  solved and the walls are mesh shaders, 8 GB of RAM and no FSR2 library.
- Read the dump itself: 103 files, 500 GB of RPF9 archives, and `shaders.rpf`
  begins with `9FPR` (`0x52504639`), with `+0x2D` bit 0 set — the flag the open
  path uses to pick the `0x40` alignment base.
